# TicketTalk 双人独立盲审

## 分发和回收

1. 分别将 [A 包](reviewer_A.zip) 和 [B 包](reviewer_B.zip) 交给两位能阅读英语对话的独立读者。每位只收到自己的压缩包，包内有对话、轮次编号、判断规则和 CSV。请两人各自完成全部 48 条，独立判断用户最终接受的场次，并记录支持轮次，再把填写的 CSV 交回。协调人保存原始回件。
2. 将两份回件按原文件名放入本目录的 `returns` 子目录。Excel 可能自动调整时间格式，保存 CSV 后应确认时间为两位小时和两位分钟，如 `09:05`。在项目根目录运行下方命令。只有两人都填全后才会计算一致率和 Cohen’s κ。若两人答案均恒定且一致，κ 无定义，原始一致率仍有值。
3. 两人时间不同，或只有一人判断可确定时，程序会打印本轮目录。将该目录中的 `reviewer_C.zip` 交给第三位读者。该包仅含分歧对话、说明和空白裁决表。将返回的 `reviewer_C.csv` 放回该轮目录，再运行同一命令。两人一致的题目直接采用共同标签，包括共同判断无法确定的题目。第三人也可判断无法确定。
4. 程序在终端显示本次结果路径。每轮目录保存独立回件和 `agreement.json`，裁决完成后生成 `human-results.json`，含逐题结果、分母、区间和订单计数。按输入内容区分版本，改表重跑时可以追溯以前的结果。

```powershell
./.venv/Scripts/python.exe scripts/review_human.py
```

## 可以回答的问题

样本来自旧评测队列的 1,391 条对话，沿用已冻结的 48 个编号。本次逐题核对了修订实验的对话编号、输入文本指纹和参考订单。主测对应 17 条，复验对应 31 条；旧展示有 3 条对话的文字与修订输入有差异，两份新包均使用修订输入。48 条样本的推断范围仍受原抽样框限制。已有模型盲读结果保存在旧审计目录。独立盲审应从本页的两个压缩包开始。[样本与输入校验](source-lock.json)

场次冲突结果同时报告全 48 条和可比较子集。对含糊场次保留未定区间。订单结果保留原提交决定，电影、影院、票数等其他字段继续按官方参考评判。程序分别输出官方严格匹配、按人工场次评分，以及在双方场次均可判定时用同一种时间格式归一化规则进行的配对比较。时间无法判定时已提交且其他字段一致的订单记为不确定，其他字段有误的订单记为错误。Wilson 区间衡量抽样波动，场景模板的共性及读者系统偏差仍会影响推断。
