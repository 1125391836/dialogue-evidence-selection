# 第二个创新点定题稿

**正式题目：《工具调用中历史压缩引发的指代歧义与证据恢复研究》**

定题日期为 2026 年 11 月 20 日。本稿确定当前目录所对应的第二个创新点。第一项研究关注拟执行动作的风险和副作用，本题关注用户究竟指定了哪个对象。即使两个订单都符合业务操作规则，修改其中哪一单仍取决于用户的选择。两个研究可以共用可重置的客服环境，分别评价策略违规和错对象写入。[第一个研究的项目说明](../第一个研究/README.md)

## 可直接写入开题报告的表述

工具型智能体执行长对话任务时，需要压缩历史交互。对于“上一份”“刚才选中的那单”等请求，候选对象的编号可以完整保留，而决定用户指向哪个对象的顺序、限定条件或确认记录可能丢失。本研究考察历史压缩在何种条件下把原本可确定的操作对象变得含糊，以及由此增加的错对象操作和重复询问。在固定请求、工具和业务状态的条件下，比较恢复原始选择依据、保留结构化对应关系与向用户澄清的效果，量化不同历史预算下可避免的操作错误、交互开销及其适用范围。

## 现有数据能支持到哪一步

- **原始任务可定位选择依据。** 训练题 qa_443 的用户先给出四个商品编号，随后要求购买原清单第一项。标准答案与清单第一项一致。使用项目的分词和序列化方式，含四项及其顺序的用户消息只需 103 个 token，现有整段历史块需 1,230 个。只读回放中，最近历史、BM25 和规则配对在 512、1,024、2,048 三档预算下均未保留正确编号。这证明大块选择可丢失可负担的证据，尚未观察到实际买错，亦未证明“编号俱在而顺序丢失”。按消息保留完整有序清单是这道题最值得打败的简单基线。[训练题与开发题原文](context-bundles/data/processed/mem2act-v1/cases.jsonl) · [标准调用](context-bundles/data/processed/mem2act-v1/labels.jsonl)
- **开发题可检查错误归因。** qa_162 中用户已选定酒店，但历史能找到的是预订号，工具所需的酒店 ID 没有字面出现。适当的补救可能是查酒店目录。qa_078 中两个车型都被讨论，标答选了一个，历史是否足以确定仍需人工裁决。这两种情况都不能直接计入压缩造成的错误。
- **素材足以启动审核，真实占比待测。** 在 376 道训练题和 58 道开发题中，按字段名含独立 id 且标量值至少四字符筛到 89 题，其中 70 题的入选 ID 均能在历史中直接匹配，19 题均无字面命中。这一筛查会遗漏短编号和隐式映射，也包含只有一个候选的简单题。99 道测试题本轮未做内容审核。本轮只复用了已有模型结果并做离线检查。

## 实验与裁决

1. **估计自然任务中的规模。** 按历史组从原始任务独立抽样，报告所有抽样分母，再标记有多个合理候选且完整历史足以确定目标的任务。并行保留天然歧义、后端缺映射、需重新授权或按业务规则必须确认的样本。采用人工复核，记录分歧及依据。自然样本用于估计频率，人工构造的难例单报。
2. **隔离用户选择这一变量。** 对可重置的客服订单或办公文件建立三份历史。当前请求、两个合法对象、查询返回、写入工具和环境状态完全相同。早前对话分别确定 A、确定 B、从未确定。前两份应写到不同对象，第三份应先获得用户选择。三份始终同属一个数据划分；对调对象位置、名称或编号以控制猜测捷径。从具有完整依据的任务开始，对同一历史分别运行无压缩、实际压缩、等长无关回填和关键依据回填条件。固定背景并对模型重复采样。人工删改只作机制检查，真实压缩自然发生的结果单列。
3. **判清丢了什么。** 分开记录候选编号丢失、编号仍在但顺序或确认关系丢失、依据已在但模型用错、外部映射缺失四种情况。评审者先只看压缩视图，允许“无法判断”；再以原始来源复核。不能因为两个摘要措辞不同就认定它们保留了不同选择。人工提供正确原文测可恢复空间，在线方法只读取动作发生前可见内容。
4. **让最简单的方法有机会胜出。** 同一模型上比较按消息切分的字段检索、保序列表或“候选 ID＋用户选择依据”的结构化摘要、重读原指令、按需回读原消息。各方法拥有相同的目录查询、历史访问和澄清权限；全历史作为单独参照。对比时记录历史预算、额外模型调用及总费用。澄清后的回复按一致的用户设定提供，显式分出“已有答案的重复询问”和“用户首次提供选择”。
5. **评价结果。** 从全部任务计算错对象写入、正确完成、重复询问、必要询问及额外耗时。分别公布从完整历史正确变为压缩错误、以及反向转移的比例，按历史组给配对区间。核查实际落在哪条记录，以及是否误改其他记录。相同预算下报告完整结果，并在相近正确完成率下比较错写和重复询问，防止用一律追问换来低错误率。需要自己配对构造历史、使订单或文件任务可重置并新增终态断言；现成静态题只能给参数标签。

**继续开发新方法的判据。** 在原始自然任务中能复现关系丢失，人工回填可稳定挽回操作错误，且自动方法在隔离历史组上优于细粒度检索、结构化保留或重读原指令，才把新方法收益写为贡献。若问题主要源自过大的分块，报告简单修复及适用范围；若只有人工构造才观察到，限于机制结果；若证据齐全仍频繁做错，应转向动作模型的证据利用问题。允许上述结果推翻算法假设。

## 检索范围

回看了本项目两段归档研究对话、实验设计、上一版定题与相邻第一个研究的说明。外部检索沿“工具调用对象错误 → 多步绑定漂移 → 压缩后关系丢失 → 回读还是重复询问”反复寻找反例。使用公开学术和网页检索，并核对 ACL Anthology、arXiv、期刊原页、作者项目与中文公开披露。OpenAlex 的四个补充查询为 `agent context compaction benchmark`、`agent compaction cliff`、`agent history compression recovery tool agent objects`、`agent tool context compaction retrieval benchmark`，每式浏览按相关度排序的前 12 个结果。网页补查含 `binding drift tool-augmented agents`、`agent context compaction counterfactual histories same summary different actions identifiers`、`tool agents ambiguity internally resolvable clarification benchmark` 及“对话历史 压缩 用户已经提供 重复询问 多轮工具调用 指代歧义”。另查知网、万方及高校公开网页索引，未完成库内学位论文全量检索。检索流程参考 [Scientific Agent Skills v2](https://arxiv.org/abs/2609.00065)。

**查重结论。** 截至定题日，所核对的一手来源已覆盖本题的大部分单项技术。尚未找到与本题相同的实证结论，即在候选对象和外部接口不变时，用实际压缩器测出历史中已确定的用户指代重新变得含糊所造成的错写与可避免澄清，并用天然歧义对照检验恢复收益。当前可以确定研究问题和实验边界。全球首创、部署发生率、方法增益都超出已有证据。
