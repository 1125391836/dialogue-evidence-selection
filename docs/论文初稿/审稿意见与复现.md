## 复算

在项目根目录用 PowerShell 和项目虚拟环境。先执行主实验生成新队列逐题结果，再执行对应复评。项目已经保存各项逐题数据。CPU 计时会随机器、并发载荷和缓存状态波动。

```powershell
./.venv/Scripts/python.exe scripts/ticket_learning.py --test
./.venv/Scripts/python.exe scripts/review_labels.py retrain
./.venv/Scripts/python.exe scripts/review_labels.py rescore
./.venv/Scripts/python.exe scripts/review_human.py
./.venv/Scripts/python.exe scripts/review_selector_ablation.py
./.venv/Scripts/python.exe scripts/review_risk.py
./.venv/Scripts/python.exe scripts/review_benchmarks.py
./.venv/Scripts/python.exe scripts/review_generalization.py
./.venv/Scripts/python.exe scripts/review_scenario_holdout.py
./.venv/Scripts/python.exe scripts/review_sgd_transfer.py
./.venv/Scripts/python.exe scripts/review_generative.py
./.venv/Scripts/python.exe -m unittest discover -s tests
```

最后一个实验默认使用已保存的相同提示的模型响应重新评分。要独立生成响应，使用 `scripts/review_generative.py --refresh`，先在单独的终端启动本机服务，再运行脚本。模型为 Qwen2.5-1.5B-Instruct Q4_K_M，SHA-256 和提示见[生成实验协议](../../runs/review-generative/protocol.json)。使用已校验的 llama.cpp b6330 的 Windows Vulkan 运行时，在模型目录下用相对路径加载 GGUF。实验不需要云端账户。

```powershell
cd data/external/review-reader
./llama-server.exe -m qwen-1.5b-q4.gguf -ngl 99 -np 4 -c 8192 -t 4 --host 127.0.0.1 --port 18756
```
