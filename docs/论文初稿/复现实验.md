# 初稿实验索引

在 `context-bundles` 项目根目录打开 PowerShell，使用项目的虚拟环境。现有数据已保存在本机。本轮使用 Python 3.14.6、scikit-learn 1.9.1、NumPy 2.5.5、SciPy 1.18.1 以及 tokenizers 0.23.3，无需付费模型。下列命令会重新生成对应实验结果。

## 主表和图

```powershell
.\.venv\Scripts\python scripts\ticket_learning.py --test
.\.venv\Scripts\python runs\ticket-learning\audit.py
.\.venv\Scripts\python scripts\order_risk_audit.py
.\.venv\Scripts\python scripts\confirmation_audit.py
.\.venv\Scripts\python scripts\paper_figure.py
```

- [训练、开发与主结果](../../runs/ticket-learning/summary.json)；[冻结的划分和选项](../../runs/ticket-learning/protocol.json)。TicketTalk 上游版本为 `d92cb6af3005f1dc09c39e75e7daf4a04905e00b`。
- [453 段对话的逐题订单](../../runs/ticket-learning/test-details.jsonl)；[938 段复验记录](../../runs/ticket-learning/replication-details.jsonl)。每个条件的 `selected` 给出选中的原话编号，`args` 为拟写订单，`confidence` 为整单分数，`outcome` 为按共同阈值执行后的结果。未写入时仍可查看模型原先拟填的参数。
- [覆盖率与相似模板分析](../../runs/ticket-learning/audit.json)；[独立阈值审计](../../runs/order-risk-audit/summary.json)；[按用户确认复核后的差值](../../runs/confirmation-audit/summary.json)；[抽样原始 JSON 对照](../../runs/ticket-learning/reference-review.md)。
